＃＃＃実行ファイルについて
chmod +x sis_manager.py
./sis_manager.py
でインストーラーが起動して使用できます。
./sis_manager.py package_install 　で環境を整え
./sis_manager.py try　でデスクトップ環境を試用
./sis_manager.py deploy　でデスクトップ環境をインストール
./sis_manager.py isntall でフルインストール(試験環境推奨)


＃＃＃ソースコードは以下のディレクトリに格納されています。
デスクトップ環境：sis-ui
MDMサーバー側：mdm_server
各種シェルスクリプト：scripts、tools、live、リポジトリ直下
